
Статья из разряда для себя, но может пригодится тем, кто решит пройти путь с начала. У меня была задача подключить домашний NAS с фильмами и сериала к Proxmox, на котором крутился бы медиа сервер.
Стак получился такой:
Gluetun - для доступа к внешнему хосту, где развернута система "улучшения" работы интернета
Powlarr - основная БД поиска данных
Jackett - добавление мест поиска которых нет в Powlarr
Flaresolverr - обход капчи
Sonarr - поиск сериалов
Radarr - поиск фильмов
Seerr - единая точка входа для поиска
qBittorrent - для скачивания
Jellyfin - сам медиа север

В моем варианте все сервисы общаются через единую сеть что упрощает настройку и дает все доступ во внешний мир, но закачка и просмотр происходят в локальной сети что не скажется на трафике.

Для начала после установки нужно создать LXC контейнер с Docker в котором и развернем медиа сервер. Проще всего это сделать используя готовые скрипты, найти можно на сайте

Для развертывания LXC + Docker в консоли Proxmox выполняем команду
```
var_os='debian' bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/ct/docker.sh)"
```
После создания LXC-контейнера с **Docker** нужно установить **Portainer**. Как его ставить и настраивать, подробно описано в инструкции, поэтому не буду уделять этому внимание. 

Для того чтобы LXC увидел **NAS**, нужно настроить подключение. Для этого необходимо установить `CIFS`. Выполним установку командами:

```bash
apt update
apt install cifs-utils -y
```

Создадим каталоги к которым будем монтировать NAS, у меня /mnt/pve/TrueNAS
```
mkdir -p /mnt/TrueNAS
```
Создадим файл с УЗ для подключения к NAS
```
nano /root/.smbcredentials
```
И добавим строки с данными от пользователя NAS
```
username=nas_user
password=nas_pass
```
Установим права доступа только для root:
```
chmod 600 /root/.smbcredentials
```
Откройте файл /etc/fstab для редактирования:
```
nano /etc/fstab
```
Добавляем запись одной строкой:
```
//192.168.1.1/TrueNAS /mnt/TrueNAS cifs credentials=/root/.smbcredentials,iocharset=utf8,noperm,vers=3.0,_netdev 0 0
```
Применяем конфигурацию без перезагрузки:
```
mount -a
```
Если ошибок нет, проверяем содержимое:
```
ls -ls /mnt/TrueNAS
```
Дальше добавим строки в конфиг LXC чтобы он мог монтировать их, а так же заранее добавим строки необходимые для Gluetun
```
mp0: /mnt/TrueNAS/,mp=/mnt/TrueNAS/
lxc.cgroup2.devices.allow: c 10:200 rwm
lxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file
```
Последние строчки позволят контейнеру использовать сетевую карту для подключения к внешнему хосту, который поможет "лучше" работать поисковикам.

После всех процедур мы можем задеплоить наш [docker compose файл](https://github.com/ISOIEC/Complete-arr-stack-for-a-media-server-in-Docker./blob/main/docker%20compose.yml)

При настройке приложений, рекомендую указывать не IP, а **gluetun:port** сильно упрощает жизнь и не нагружает роутер. Для подключения к торрент указывать **qbittorrent** вместо IP
По настройке каждого приложения возможно будут дополнения, но инструкций полно в интернете
